# PV168 Project: TODO List

This project aims to develop a desktop application designed to help users organize and manage their tasks effectively. 
The application will allow users to create tasks with key details such as:
- Task Description: What the task entails.
- Location: Where the task needs to be done.
- Due Time: When the task is due.
- Estimated Time: How long the task is expected to take.

Additionally, users will be able to categorize tasks for better organization. The application will include a filtering feature, enabling users to sort tasks based on their progress status, allowing for efficient task management and prioritization.
